# Release v1.0.0 — دنیای کوچیک ما

**Release Date:** 2026-08-20

## Features
- Two-person token pairing system
- App Lock (PIN + biometric architecture)
- Splash screen with brand identity
- RTL Persian UI
- Dashboard with smart cards
- Mood system (9 moods + 5 metrics)
- Partner mood awareness
- Memory vault (create, favorite, privacy)
- Real-time chat (local + sync-ready)
- Shared calendar
- Room database (19 entity tables)
- Backend REST API
- WebSocket server
- Sync engine with offline queue
- Complete API (17 route groups)
- GitHub Actions CI/CD

## Security
- Android Keystore for all secrets
- Three-token architecture
- Server-side couple isolation
- Rate limiting
- Audit logging

## Known Issues
- Font files are placeholders (download Vazirmatn separately)
- Google Drive integration pending OAuth setup
- GitHub backup worker pending GITHUB_TOKEN configuration

## Build Info
- Android: Kotlin 1.9.24 + Jetpack Compose
- Backend: Node.js + TypeScript
- Database: PostgreSQL
- Min SDK: 26 (Android 8.0)
- Target SDK: 34 (Android 14)
